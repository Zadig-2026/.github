# .github
Zadig — компактная утилита для Windows для установки и замены USB-драйверов устройств на WinUSB, libusb-win32, libusbK и другие поддерживаемые варианты. Часто используется при работе с FPV-полётными контроллерами и STM32 DFU, когда Betaflight, INAV или программы прошивки не могут получить доступ к подключённому устройству.
