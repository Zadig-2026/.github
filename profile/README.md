## Обзор проекта

**Zadig** — портативная утилита для **Windows**, предназначенная для установки и замены USB-драйверов для подключённых устройств. Программа особенно полезна для оборудования, которому требуется доступ через **WinUSB, libusb-win32 или libusbK**, но Windows автоматически назначила другой или неподходящий драйвер.

В FPV-экосистеме Zadig часто применяется при диагностике проблем с полётными контроллерами и устройствами на базе **STM32**. Типичный сценарий — контроллер успешно переводится в **DFU Mode**, однако Betaflight Configurator, INAV Configurator или другая программа прошивки не может его обнаружить из-за неправильно установленного USB-драйвера.

Zadig не является программой для настройки или прошивки самого полётного контроллера. Его задача — изменить привязку Windows-драйвера для выбранного USB-интерфейса, после чего специализированное программное обеспечение сможет взаимодействовать с устройством.

## Основные возможности

| Функция | Назначение |
|---|---|
| **USB Device Detection** | Отображение подключённых USB-устройств |
| **WinUSB** | Установка универсального Microsoft USB-драйвера |
| **libusb-win32** | Установка драйвера для совместимых libusb-приложений |
| **libusbK** | Альтернативный драйвер семейства libusb |
| **Driver Replacement** | Замена уже назначенного Windows-драйвера |
| **Driver Installation** | Установка драйвера для выбранного USB-устройства |
| **DFU Devices** | Работа с устройствами, находящимися в режиме DFU |
| **STM32 Bootloader** | Исправление типичных проблем с доступом к STM32 DFU |
| **Portable Utility** | Запуск без полноценной установки приложения |
| **Device Selection** | Ручной выбор конкретного USB-интерфейса |

Zadig предоставляет низкоуровневый доступ к драйверам, поэтому перед нажатием **Install Driver** или **Replace Driver** необходимо убедиться, что выбрано именно нужное устройство. Замена драйвера системного USB-устройства по ошибке может нарушить его нормальную работу.

## Zadig в FPV и STM32 DFU

Для FPV-пилотов Zadig наиболее полезен при работе с полётными контроллерами, которые необходимо прошить через **STM32 DFU bootloader**. В этом режиме контроллер определяется Windows отдельно от обычного последовательного COM-подключения.

Если DFU-драйвер настроен неправильно, устройство может присутствовать в Windows, но отсутствовать среди доступных устройств в Betaflight Configurator или другом инструменте прошивки. Zadig позволяет выбрать соответствующий STM32 DFU-интерфейс и назначить ему совместимый драйвер.

| Компонент | Роль |
|---|---|
| **Zadig** | Установка или замена USB-драйвера |
| **STM32 DFU** | Режим загрузчика микроконтроллера |
| **WinUSB** | Драйвер, используемый многими USB-инструментами |
| **Betaflight Configurator** | Настройка и прошивка FPV-контроллеров |
| **INAV Configurator** | Настройка совместимых FC на INAV |
| **STM32CubeProgrammer** | Работа с STM32 и режимом DFU |
| **Flight Controller** | Устройство, для которого может потребоваться исправление драйвера |

Обычный режим полётного контроллера и DFU являются разными USB-интерфейсами. Поэтому работающий COM-порт не гарантирует, что Windows правильно настроена для подключения этого же контроллера в DFU Mode.

## Выбор и установка драйвера

После запуска Zadig необходимо выбрать именно то USB-устройство, для которого требуется изменить драйвер. При необходимости список можно расширить через **Options → List All Devices**. Перед установкой следует внимательно проверить название устройства и текущий драйвер.

Для многих инструментов, использующих стандартный USB API Windows, применяется **WinUSB**. Однако выбор драйвера всегда должен соответствовать требованиям конкретной программы и устройства — универсального варианта для абсолютно любого оборудования нет.

Zadig также показывает текущий и выбранный новый драйвер, что позволяет проверить изменение до его применения. Если проблема связана не с драйвером, а с повреждённым USB-кабелем, отсутствием питания или аппаратной неисправностью устройства, замена драйвера её не устранит.

## Быстрый старт

1. Подключите необходимое USB-устройство к компьютеру.
2. Для FPV-контроллера при необходимости активируйте **DFU / Bootloader Mode**.
3. Запустите **Zadig** с правами администратора.
4. При необходимости включите **Options → List All Devices**.
5. Выберите только нужный USB-интерфейс.
6. Проверьте название устройства перед изменением драйвера.
7. Выберите драйвер, требуемый используемой программой.
8. Нажмите **Install Driver** или **Replace Driver**.
9. Дождитесь завершения операции.
10. Повторно откройте Betaflight, INAV, STM32CubeProgrammer или другое целевое приложение и проверьте подключение.
